Kestrel

A Reticulum / LXMF messenger. This page hosts the app source for AltStore and SideStore, so the iOS app can be installed and updated automatically.

Add the source

Source URL: https://ostapyrih.github.io/kestrel/altstore.json

Add to AltStore Add to SideStore

Or add it by hand: open Browse, then Sources, tap +, and paste the URL above. Then open Kestrel in the source and tap Free to install it.

The IPA is unsigned: AltStore and SideStore sign it with your own Apple ID, so a free Apple ID needs a refresh every 7 days (both do it automatically). On iOS 16 and later, enable Developer Mode first.
